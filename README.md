# handmade-pet-goods

文鳥・オカメインコ・モモンガなど小動物向けの手作りグッズのネットショップ。

- 計画書: [docs/計画書.md](docs/計画書.md)
- 開発の決まりとコマンド: [CLAUDE.md](CLAUDE.md)

React（Vite + TypeScript）と Firebase（Hosting / Firestore / Storage / Functions / Auth）で作っています。
開発とテストは練習用の Firebase（エミュレーター、プロジェクトID `demo-handmade-pet-goods`）だけで動きます。
